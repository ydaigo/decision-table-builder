# Decision Table Builder

システムエンジニア向けのディシジョンテーブル作成ツールです。条件と動作を定義すると全組み合わせの表を作り、Markdown でコピーして Notion などにそのまま貼り付けられます。

HTML 1 枚で動きます。サーバーもビルドも不要です。

## 使う

- ブラウザで開く: **[GitHub Pages](https://ydaigo.github.io/decision-table-builder/)**
- 手元で使う: `index.html` をダウンロードしてブラウザで開く

入力内容はブラウザ内にだけ保存されます。サーバーへは何も送信されません。

## できること

| | |
| --- | --- |
| 表の生成 | 条件の値の全組み合わせからルールを一括生成。条件を後から追加すると既存ルールを自動で展開し、再生成しても入力済みの動作は引き継ぐ |
| 表示の切替 | ルールを列に置く縦表（伝統的なディシジョンテーブル）と、1 ルール 1 行の横表 |
| 条件のグループ化 | 条件にグループ名を付けると、連続する同じグループがひとまとまりで表示される |
| チェック | 全組み合わせの網羅、ルールの重複、動作の未入力、定義外の値、離れたグループを常時表示 |
| ルールの整理 | N/A（発生しない組み合わせ）の指定、動作が同じルールの自動まとめ、並べ替え、複製、コピーと貼り付け。ルールの右クリックでメニューが開く |
| 出力 | Markdown と CSV をクリップボードへコピー。`-` と `N/A` の凡例付き |
| その他 | ライト / ダークテーマ、JSON での保存と読み込み、元に戻す / やり直す |

## 表記

| 記号 | 意味 |
| --- | --- |
| `-` | この条件は結果に影響しない（どちらでもよい） |
| `N/A` | 発生しない組み合わせ |

## 出力の例

```
|                 |                      | R1   | R2   | R3   | R4   |
| --------------- | -------------------- | ---- | ---- | ---- | ---- |
| **条件**        |                      |      |      |      |      |
| 会員            | 会員ランク           | 無料 | 無料 | 有料 | 有料 |
| 注文            | 購入金額 5,000円以上 | ○   | ×    | ○   | ×    |
| **動作 / 結果** |                      |      |      |      |      |
|                 | 送料無料             | ○   | ×    | ○   | ○   |
```

条件の値は既定が ○ と × です。カンマ区切りで自由に変えられるので、3 値以上や「ゴールド, シルバー, 一般」のような言葉も使えます。

## ショートカットキー

ツール内の「⌨ ショートカット」ボタン、または `?` キーで一覧を開けます。Windows と Mac の両方を併記しています。

セルの操作は Notion のテーブルと同じ考え方です。矢印でセルを移り、Enter で値の候補や入力に入り、Esc で戻ります。
